# Adjoint upload bundles

Each `.txt` file combines all headers and source files for one adjoint module. Every section is labelled with the original repository path.

- `core.txt` — 12 original files
- `diagnostics.txt` — 5 original files
- `objective.txt` — 12 original files
- `operators.txt` — 11 original files
- `optimization.txt` — 10 original files
- `time_dependent.txt` — 10 original files
- `adjoint_benchmarks.txt` — 210 text files from 5 adjoint benchmarks; generated output and binary/media files excluded
