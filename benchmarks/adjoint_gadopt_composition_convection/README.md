# G-ADOPT-equivalent composition twin experiment

This benchmark transfers the background state, geometry, free-slip walls,
Q2/Q1 Stokes discretization, 80 fixed timesteps, unit gravity, unit viscosity,
and scaled diffusivity from `adjoint_gadopt_mantle_convection` to a chemical
composition terminal-observation experiment. The full reference is advanced
through step 80. As in the temperature twin, the inverse reconstructs the
reference state at step 70 from the terminal field at step 80 and therefore
uses exactly ten forward transitions per objective evaluation.

The transported control and observation field is `chemical`, initialized with
the same analytic profile used for the G-ADOPT temperature reference:

```
C(x,y) = 0.5*(erf(3*(1-y)) + erf(-3*y) + 1)
         + 0.1*exp(-0.5*((x-0.5)^2+(y-0.2)^2)/0.1^2).
```

The ASPECT simple material law is
`rho = rho_0 * (1 - alpha * (T-T_0)) + Delta_rho * C`. This benchmark sets
`rho_0 = 1`, `alpha = 0`, and `Delta_rho = -1`. Therefore its compositional
buoyancy term is exactly `rho = 1 - C`, the same density contrast generated by
the G-ADOPT benchmark's `rho = 1 - T` when `C` is initialized from that
temperature profile. The negative value is intentional: composition one is
lighter, just as the hot G-ADOPT anomaly is lighter. A positive density
increase would reverse the flow unless the composition were redefined as
`1-T`.

Unlike G-ADOPT temperature, ASPECT chemical composition has no physical
thermal-diffusion term or imposed top/bottom Dirichlet values. Thus this is a
controlled composition-advection counterpart with identical initial buoyancy,
not a claim of identical 80-step evolution. Temperature is retained only as
ASPECT's neutral auxiliary field (`T=0`, `alpha=0`).

Build the terminal-composition exporter and the exact-profile initial-condition plugin:

```bash
cmake --build build-release --target van-keken-terminal-composition-plugin
cmake -S benchmarks/adjoint_gadopt_composition_convection/plugin \
  -B build-release/gadopt-composition-initial-plugin \
  -DAspect_DIR=$PWD/build-release
cmake --build build-release/gadopt-composition-initial-plugin
```

Then run the serial reference forward input. Its step-70 field is available as
`results_70to80/reference/solution/solution-00070.0000.vtu`, and its final
structured observation is written to
`results_70to80/reference/terminal_composition.txt` at step 80. The inverse
begins from the unperturbed analytic background and advances ten steps,
exactly as the temperature twin's iteration-zero control does.

## Step-70-to-80 composition twin and figures

`reference_forward_70to80.prm` and
`inverse_initial_composition_70to80.prm` reconstruct the reference step-70
composition from the step-80 terminal observation. Their complete outputs are
under `results_70to80/`. Regenerate the accepted-control/error panels,
terminal comparison, iteration history, and four-column reconstruction
storyboard with:

```bash
conda run -n hang python analysis/make_70to80_plots.py
```

## Physical 0-to-80 composition twin and figures

`reference_forward_0to80.prm` and `inverse_initial_composition_0to80.prm`
reconstruct the physical step-0 composition field from its step-80 terminal
observation. Their complete outputs are under `results_0to80/`. Regenerate
the accepted-control/error panels, terminal comparison, iteration history, and
four-column reconstruction storyboard with:

```bash
conda run -n hang python analysis/make_0to80_plots.py
```
